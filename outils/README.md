# To watch… or not, outils

Copie des outils qui font vivre le site https://monyanjos.github.io/to-watch-or-not/

- `update.py` : met à jour `data.json` à partir des listes Netflix, Prime Video et Apple TV relevées dans Chrome (lancé chaque matin par une tâche planifiée Claude sur le Mac).
- `ac.py` : recherche les notes AlloCiné d'un titre.
- `google-apps-script.gs` : stockage partagé des coches « Déjà vu » et des retraits (Google Apps Script, déployé en application Web).

Les originaux sont dans `~/ToWatchOrNot` sur le Mac ; ce dossier en est une copie de sauvegarde.
